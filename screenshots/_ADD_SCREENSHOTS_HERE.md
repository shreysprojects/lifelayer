# Drop your screenshots in this folder

The README references these exact filenames (PNG). Add whichever you have — the
tables will render them automatically. Delete rows in the README for any you skip.

- `dashboard.png`    — home / daily dashboard
- `routine.png`      — a routine's step-by-step runner or task list
- `workout.png`      — a workout with the muscle map
- `nutrition.png`    — the meals / macros screen
- `friend.png`       — a friend profile / calendar
- `explore.png`      — the community Explore feed
- `ai.png`           — the AI routine coach or AI Looks result
- `onboarding.png`   — onboarding / goals

## How to capture on iPhone
- **Screenshot:** press Side button + Volume Up. Find them in Photos → AirDrop/email to your PC → rename per the list above.
- **Demo video:** Settings → Control Center → add **Screen Recording**. Swipe into Control Center, tap ⏺, walk through the app for 30–60s, stop. Trim in Photos. Then either upload to YouTube (Unlisted) and paste the link in the README, or drag the .mp4 into the README on github.com and GitHub will host it inline.

Once you've added the images, you can delete this file.
